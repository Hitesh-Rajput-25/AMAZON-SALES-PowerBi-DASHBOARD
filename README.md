# 📊 Amazon Sales & Reviews — Power BI Dashboard

## 📌 About This Project
In this project, I created an interactive *Power BI Dashboard* to analyze Amazon sales and customer review data from *2019 to 2022*. The dashboard tracks total revenue, customer feedback, quarterly growth, and top-performing product categories.

---

## 🛠️ Tools & Skills Used
- *Power BI Desktop* (Data Modeling, Interactive Visuals & Slicers)
- *Power Query* (Data Cleaning & Transformation)
- *KPI Cards, Line Charts, Bar Charts & Pie Charts*

---

## 🔍 Key Insights Found
1. *Overall Performance:* Generated *$8M in Total Sales* across *59M Total Reviews, with an average sale value of *$95**.
2. *Quarterly Growth:* *Qtr 4* recorded the highest sales share (*40.4% / $3M), showing strong year-end shopping demand, followed by Qtr 3 (27.2%*).
3. *Top Categories:* *Cameras* and *Mobile Accessories* led both in total sales revenue and customer feedback volume.
4. *Interactive Filtering:* Added Year slicers (*2019–2022*) so users can dynamically filter sales and review trends by year.
